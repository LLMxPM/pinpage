# 自选行情示例

已接入工作台内置示例库，也可独立导入页面包。脚本、样式和图表资源随包提供，报价和真实分时需要联网；卡片明确标记网络依赖。

## 使用

- 复用已有开发服务，访问 `http://127.0.0.1:1420/examples/stocks/site/index.html`。
- 也可从「示例库 → 自选行情」直接添加；随包提供紧凑、标准与宽屏命名窗口预设。
- 执行 `pnpm examples:pack`，将生成的 `dist/examples/stocks.pinpage` 通过「添加页面 → 导入页面包」导入。也可按目录导入本工具的 `site/`，目录导入不应用清单中的默认窗口预设。
- 默认布局为 `400 × 640` 无边框置顶浮动窗，并请求背景透明。推荐在 PinPage「窗口设置」中调整为以下尺寸，页面自动适配；页面本身不调用宿主窗口接口。不支持透明的平台由宿主回退。
- 设置中使用显式市场代码，如 `sh000001`（上证指数）、`sz000001`（平安银行）、`600519.SH`，最多十二个。验证版暂不提供名称搜索或自动推断纯数字代码。
- 点击行情行切换当前标的的价格、昨收、今开、最高、最低和真实分时趋势；自选可以上移、下移、移除。报价刷新支持 15、30、60 秒或仅手动，默认 30 秒。
- 支持在已有自选中按名称或代码筛选，以及自选顺序、名称、涨幅优先三种展示排序；排序不改变原始自选顺序，搜索词不持久化。设置可切换红涨绿跌或绿涨红跌。
- 自动刷新在隐藏窗口时至少间隔一分钟，断网时停止定时请求，恢复联网后按自动刷新偏好恢复；仅手动模式不会因恢复可见而自动请求。
- 行情列表和设置隐藏滚动条，仍可使用滚轮、触控板或键盘滚动，列表可聚焦后按方向键、PageDown 或 End。小窗口会压缩展示内容，宽屏使用左右分栏。
- 页面设置提供深浅主题、柔光底板／无底板、25%～100% 底板不透明度与分时开关。宿主关闭透明时保持完整底色，开启透明时跟随底板设置；不会将文字整体变淡。

| 形式 | 逻辑尺寸    | 布局                                         |
| ---- | ----------- | -------------------------------------------- |
| 紧凑 | `280 × 420` | 集中价格与涨跌，缩小趋势图，自选列表保留滚动 |
| 标准 | `400 × 640` | 上方选中行情与趋势，下方自选列表             |
| 宽屏 | `720 × 440` | 左侧自选，右侧行情、趋势和详情               |

## 数据与边界

- 批量报价请求为 `https://qt.gtimg.cn/q=<逗号分隔的市场代码>`，使用 GB18030 解码并只解析赋值文本。分时请求为 `https://web.ifzq.gtimg.cn/appstock/app/minute/query?code=<市场代码>`，使用 JSON 数据。二者均由前端直接跨域读取，不加载远程脚本、不使用 JSONP、代理或宿主 IPC，不携带登录凭据。
- 报价字段位置来自本次接口响应验证，并非供应商承诺的稳定开放 API 合同。接口、跨域行为和限流规则可能变化，不保证实时性或长期可用性。公开产品分发需另行确认上游使用条件。
- 界面分别显示每个标的的北京时间行情时间和最近请求成功时间。非当日报价、本轮缺失与请求失败明确提示；缺失价、盘前零开高低价显示为 `—`，不补成有效报价。
- 分时只请求当前选中的标的，随报价轮询检查，普通刷新同一标的最多每分钟一次；仅手动模式随手动刷新，手动请求也至少间隔三秒。失败递增退避，最长五分钟。切换标的或删除时，迟到响应不会覆盖当前选择或恢复已删除的内容。
- 分时横轴以已取得的时间范围缩放，保留缺失分钟间隔并压缩午休；不补造未来、缺失或随机数据。单点仅绘制圆点，空数据提供说明，失败保留原图并标记缓存。图表可用鼠标查看时间与价格，或聚焦后使用左右方向键、Home、End。
- 分时日期、即时行情时间分别展示；昨收基线来自该分时响应，不混用其他日期的报价。不依据本机星期或接口成功推断交易中、休市或停牌。
- 自选、当前选择、外观、刷新频率、最近报价与分时缓存保存到兼容旧版的 `pinpage-stocks-v1`，不含 API 密钥。缓存恢复后仍以原行情时间展示；页面包导出可能携带这些自选和缓存数据。
- 所有字体、样式与脚本均随包提供；只有行情依赖网络。断网时保留已取得的行情，首次离线没有缓存时显示空报价。

## 验证

- 报价、分时、请求竞态与存储约束：`node --test tests/stocks.test.mjs tests/stocks-trend.test.mjs`。
- 包含本地筛选排序和其他示例状态约束的统一入口：`pnpm test:examples`。
- 格式：`pnpm exec prettier --check examples/stocks tests/stocks.test.mjs tests/stocks-trend.test.mjs`。
- 标准包：`pnpm examples:pack`，以及 `cargo test --manifest-path src-tauri/Cargo.toml --lib examples::tests`。
- 浏览器与 Windows WebView2 的实际验证范围见 [开发与构建](../../docs/development.md#当前状态与验收)。接口成功不能替代真实盘中延迟和长时间稳定性测量。
