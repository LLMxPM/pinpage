# PinPage v0.3.0

本版面向 Windows x64，新增透明桌面工具、页面级窗口预设、本机智能体 CLI 与七个内置示例。macOS 继续作为实验性平台，仅提供源码与 CI 验证包，不包含在本次正式安装包中。

## 新增与改进

- Windows 浮动与桌面页面支持透明背景；无边框直角与圆角样式清理系统阴影和描边，切换外观保留页面运行状态。
- 窗口预设归属单个页面，支持命名列表、编辑与一键应用；页面包可携带默认布局和命名预设。
- 增加随安装包分发的 `pinpage-cli` 和独立「智能体与 CLI」面板，提供本机页面管理、更新、预设、导出、诊断及桌面截图。控制入口默认关闭，页面制作技能由用户主动安装或更新。
- 增加只读宿主信息、共享系统采样，以及经逐页授权的文件夹只读能力。
- 示例库整合为时间工具、便签与待办、日历与倒数日、轻量看板、自选行情、文件夹和系统监控七项，提供命名窗口布局；行情需要联网，文件夹需要授权。
- 增加可选 Windows 登录自启；默认 Ctrl + 左键拖动无边框页面，直接右键打开窗口菜单，可按页面交给网页处理右键。
- 合入 macOS 实验性浮动窗口与可选 Option 拖动支持，保留默认／实验两组 CI；修复 macOS 打包误构建 Windows CLI 资源的问题。

## 升级与数据

- v0.2.0 用户可使用应用内更新；v0.1.0 用户需手动安装本版。
- 配置格式从 `schemaVersion = 1` 自动迁移到 `2`：已被页面引用的全局预设复制到对应页面，未引用模板不再保留。建议升级前备份应用配置目录。
- 已添加的示例副本不会自动覆盖；新建示例可使用新版工具。旧时钟与待办标识继续兼容映射，独立页面之间不自动合并数据。
- 应用升级不会自动覆盖已安装到智能体目录的页面技能，需主动更新。

## 当前验收边界

Windows 跨版本 updater 安装、重启数据保留、交互式 PATH 选择、混合 DPI／多显示器、新示例完整原生交互及长期资源趋势仍待专项验收。macOS 的既有实机记录限于一台 Apple Silicon Mac 的核心窗口流程，不代表本版全部功能、Intel 或 Retina／多显示器已通过。

详情见[当前状态与验收](https://github.com/LLMxPM/pinpage/blob/v0.3.0/docs/acceptance.md)和[平台支持](https://github.com/LLMxPM/pinpage/blob/v0.3.0/docs/platforms.md)。
