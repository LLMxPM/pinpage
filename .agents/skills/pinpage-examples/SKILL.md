# PinPage 示例页

创建可独立运行、可导入和导出的轻量桌面工具页。窗口生命周期、置顶、桌面模式和拖动由 PinPage 提供，示例只负责页面内容。

## 确定范围与参照

- 以仓库根目录的 [AGENTS.md](../../../AGENTS.md) 为协作规范；本文中的代码路径均相对仓库根目录。
- 先判断请求是制作独立页面、修改既有示例，还是新增内置示例。需要加入示例库时，按 [接入与验证](references/integration.md) 完成注册与内嵌资源；只要求页面原型时无需扩展示例枚举。
- 参考最接近的实现：[计时器](../../../examples/timer/site/index.html) 演示 ES 模块、JSON、截止时间和 IndexedDB；[便签](../../../examples/notes/site/notes.js) 演示编辑即保存；[待办](../../../examples/checklist/site/checklist.js) 演示输入校验和安全渲染；[时钟](../../../examples/clock/site/clock.js) 演示基于真实时间刷新；[文件夹](../../../examples/folder/site/app.js) 演示逐页授权与只读浏览；[系统监控](../../../examples/system-monitor/site/app.js) 演示共享采样轮询与降级。
- 页面需要宿主能力时先读 [原生能力契约](references/native-capabilities.md)：分级模型、命令与错误码、授权生命周期、出站 CSP 和可复制的薄封装；不要自行发明 IPC 通道或放宽边界。
- 页面内容默认中文，现有示例不随工作台语言切换。示例库卡片标题和新建页面名称属于宿主文案，接入时维护中英文资源。

## 页面与资源边界

- 新工具使用 `examples/<工具名>/manifest.json` 和 `site/` 的标准包源码布局，入口相对于 `site/`，通常为 `index.html`。按职责拆分 CSS、JavaScript 和数据文件，资源留在本工具的站点内；清单格式见 [页面包与示例制作](../../../docs/page-packages.md)。
- 示例是独立静态站点，不经过工作台的 Vue/Vite 打包。优先使用浏览器原生 HTML、CSS 和 JavaScript，不直接引用 `src/`、`@tauri-apps/api`、包名导入或 Vite 专用路径。
- 默认离线可用，必要字体、图标、图片和数据随页面提供；不要引入 CDN、远程字体或依赖远程接口的占位功能。用户明确要求联网能力时，说明依赖并处理断网状态。
- 资源使用站点内相对路径，例如 `./style.css`、`./main.js`、`fetch('./data.json')`。避免绝对磁盘路径、`file://`、开发服务器地址和越出站点根目录的引用；不要写死页面 ID 或本地协议主机名。
- `site/` 中的真实文件按相对目录自动打包，不维护 Rust 逐文件清单。检查 CSS 的 `url()`、JS 模块依赖和动态读取的数据都落在本工具站点内，不使用符号链接或目录联接。
- 带外部资源文件的页面应按目录导入；单 HTML 导入只复制该 HTML。使用 ES 模块或 `fetch` 时，通过 HTTP 开发服务或 PinPage 导入预览，不能用 `file://` 打开失败推断本地协议不可用。
- 内容页是不受信任页面，不获得 Shell 或窗口管理权限，不放宽工作台 CSP 或资源协议边界来适配示例。宿主能力分级提供：L0 环境信息（`host_info`、`system_stats`）只读默认可用；L1 文件夹只读（`folder_*`）经原生选择器逐页授权、以根目录为边界；写入、删除等更高权限暂不提供。契约见 [原生能力契约](references/native-capabilities.md)。

## 小窗口与透明背景

- 优先呈现工具的核心信息和操作，避免把常驻工具做成完整管理后台。布局适应窗口缩放，长内容可换行或滚动，窄窗口仍能访问主要操作；不要通过全局 `overflow: hidden` 隐藏必需内容。
- 使用系统字体、清晰的数字排版和适度留白。输入有标签，图标按钮有可访问名称，键盘焦点可见；持续更新的时间数字不要每秒触发读屏播报。
- 按 [用户指南：编写透明页面](../../../docs/user-guide.md#编写透明页面) 接入宿主提供的顶层文档变量。关闭透明时为 `1`，开启时为 `0`，普通浏览器通过回退值保持底色：

  ```css
  /* 功能：跟随 PinPage 透明偏好切换背景，独立预览时保留底色。 */
  html,
  body {
    background: rgb(250 251 248 / var(--pinpage-background-opacity, 1));
  }
  ```

- 检查 `html`、`body` 和覆盖整页的容器，避免后续不透明底色遮住桌面。局部面板可以保留自身底色或 alpha；图片、Canvas 和 iframe 需分别处理。不要用整页 `opacity` 淡化文字与控件，也不要由页面脚本覆盖宿主变量。
- 透明切换应仅改变外观，保持正在编辑或计时的状态。透明背景不会自动提供鼠标穿透；原生透明效果、DPI 和桌面模式需在真实桌面验证。
- 不在页面中实现原生拖窗、系统边框或窗口按钮，不默认拦截 PinPage 的修饰键拖动和右键菜单手势。
- 为工具在清单中提供合适的可选 `windowPreset`，包括逻辑尺寸、归一化位置和外观字段。它只初始化新页面，不创建全局预设；跨平台不支持的能力由宿主回退。不要把作者的页面 ID、绝对坐标或应用设置写入包。

## 数据与持续运行

- 刷新、关闭再开启和应用重启都会重建页面内存。需要保留的内容与偏好由示例主动写入 localStorage 或 IndexedDB；不要把宿主保留页面记录等同于保存 JS 运行态。
- 存储键和数据库名采用工具专属、可识别的版本命名，例如 `pinpage-<工具名>-v1`。恢复时检查类型、范围与数量，损坏数据回退为可用状态；用户输入以文本节点渲染。
- 文本编辑等高价值操作及时保存，不只依赖 `beforeunload` 或关闭时才执行的防抖回调。存储不可用或配额不足时保持主要操作可用；便签、清单等用户数据保存失败要明确提示。
- 同一示例每次添加使用独立页面来源，可复用同一存储键；不要通过固定主机或全局服务把多个副本意外连接。已有副本和新副本的关系见接入指引。
- 时间类工具以当前时间或截止时间计算显示，定时器只控制刷新频率，不用累加回调次数计时；页面恢复可见或从休眠返回时重新校正。仅在显示变化时更新 DOM，不用高频循环维持静态界面。
- 不默认挂起持续可见的计时器或看板。确需减少后台工作时，恢复后补算真实状态，并说明是否影响页面行为。
- `.pinpage` 页面包可携带 localStorage、sessionStorage、IndexedDB 和可选默认窗口布局；Cookie、缓存、Service Worker 和全局预设库不在迁移范围内。内置示例分发包不携带个人存储快照。

## 验证与交付

- 先检查并复用已有开发服务；静态预览用于页面交互，Rust 内嵌内容变更还需要对应的原生构建。不要反复启动应用，也不要直接修改用户应用数据目录中的示例副本。
- 检查初次打开、核心操作、窄窗口、透明变量 `0/1`、刷新恢复，以及存储异常时的可用性；有持久化内容时覆盖关闭再开启，有计时功能时覆盖休眠后的校正。
- 使用原生能力的页面额外检查：浏览器预览的演示降级明确标注；授权取消、根失效与越界路径有可用提示；不在页面保存完整本地路径。授权模态、CSP 与真实采样数值列入实机待验收。
- 新增内置示例时，用 `pnpm examples:pack` 生成可独立导入的标准包，额外验证资源完整性、随包布局、独立副本、示例卡片和中英文名称，按 [接入与验证](references/integration.md) 选择相关检查；未实际执行的原生行为明确列为待验收。
- 交付时说明页面位置、是否已接入示例库、预览或添加方法，以及检查结果与未验证项。功能或验收结论变化时同步相关文档，保持 README 中英文版本一致。
